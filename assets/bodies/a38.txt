あとどのくらい走れるか。スタミナがリアルタイムで見える、ランナーの武器「Suunto Run 2」

Nov 20,2026 20:30

ハナサキ ( GIZMODO編集部 / Don't worry, be happy )

12 BRAVO!!!

Photo: ハナサキ

ランニングはシューズとウエアさえあればすぐにでも走り出せます。カジュアルにできるのがランニングのいいところですが、ウエアとシューズにもうひとつ加えるなら時計を優先したいところです。

ぼくが日頃から愛用している時計はSuunto Runですが、ご縁があって後継モデル「Suunto Run 2」を普段のランニングで使ってみました。2カ月ほど使用したレビューです。

## ルックスは前作とほぼ変わらないが、性能はアップ

左／Suunto Run（税込34,650円）、右／Suunto Run 2（税込64,900円）

Photo: ハナサキ

パッと見、サイズ感に変わりなし。0.2mmほど厚くなったものの（11.7mm）、そのあたりは許容範囲内。重量も3g増えた程度で35g（本体のみ）。意匠も特に変わったところは見当たりません。そのくらい似通っているので、本体だけ並べても見分けがつかないほど。ルックスで見分けるとしたら、裏返して充電の際にマグネットで接触する部分の仕様が少し違うくらい。

この日は雲ひとつない晴天でしたが、日なたでもこの視認性です

Photo: ハナサキ

さて実際に使ってみて、真っ先に感じた変化は、外で使っても画面が見やすくなったこと。画面のAMOLEDディスプレイが前作の600ニトから最大2,000ニトに大幅アップしたため、よく晴れた屋外でもしっかり視認できました。前作で特に見づらいと感じていたわけではないんですが、ここまで明るくなると「おぉ」と感心しますし、くっきりと見やすくなったのは、特にランニングなどの屋外アクティビティで際立ちます。

そして、先ほど触れた裏面の充電端子も個人的には好みでした。マグネットが強めになっていて、ピタッとくっつく。前作だと、マグネットが少し弱めのため、充電されているのかな？と不安になることもありました。Suunto Run 2は“カチッ”とハマるとすぐに充電開始の表示になるので、安心材料がひとつ増えました。

リューズ（サイド中央のダイヤルボタン）を回すか、画面をスクロールするだけでサッと残りの充電が確認できます

Photo: ハナサキ

充電といえば、バッテリーの持続時間も長くなりました。Suunto Runではバッテリー容量が295mAhだったのに対して、本作は380mAhにアップ。約29％増加したことで、たとえば屋外運動を毎日1時間行った場合、日常使用は最大8日間から最大10日間に。高精度GPSモードにおいては、最大20時間から最大24時間へそれぞれ長くなっています。

前作を使用していた際、特に充電頻度については問題ないと感じていましたが、持ちが良くなるのは嬉しいですね。ただ、それ以上にありがたかったのが、充電スピード。

ランニングに行こうと出かける直前で残りの充電が10％を切っていて、そういう時に限ってロングランを予定していて愕然としたんですが、5分も充電すれば30％くらいまで復活したのは本当に助かりました。ストレッチのひとつやふたつやっているうちに、急速充電できちゃいました。
