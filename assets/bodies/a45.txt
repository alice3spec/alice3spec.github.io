SUMA-KIYO ( GIZMODOライター )

「お、ねだん以上。」のキャッチコピーでおなじみのニトリが、なんと「オーディオ」に本格参入するとの情報が。

いつも価格以上の満足を私たちに届けてくれるニトリ、果たしてオーディオではどんな「お、ねだん以上。」を見せてくれるのか？

さっそく、ニトリ大阪本部で開催された「2026年秋冬 新作家電体験会」へ取材に行ってきました。

Photo: SUMA-KIYO

会場内にはリビングやキッチンなどの生活セットが組まれており、そこに2026年秋冬の新作家電がずらりと勢揃い。

単なる展示会ではなく、実際の暮らしの中でどう馴染むのかが一目でイメージできる空間になっていました。

## やっぱりニトリ、オーディオも本気の仕上がり

ずらりと並んだ新作家電の中で、やはり衝撃的だったのが「オーディオ製品」。

これまで白物家電や調理家電のイメージが強かったニトリが、ついに音響機器の世界へ本格参入というのは本当でした。ヘッドホンやイヤホン、スピーカーまで一気にラインアップを拡充しつつ、どれも価格を二度見するほどのクオリティに仕上がっていました。

Photo: SUMA-KIYO

まず目を引いたのが、リビングのテレビ周りをスマートにアップグレードできる「スリムサウンドバー SBR-31」（税込 2万9990円 / 2026年11月発売予定）。

設置しやすいスリム形状の本体に、専用のワイヤレスサブウーファーがセットになっており、テレビ周りの配線を増やさずに重低音までしっかり響く高音質設計になっています。

カラーはBE（ベージュ）とDGY（ダークグレー）の2色展開で、インテリアに溶け込むデザインもさすがニトリといったところ。

Photo: SUMA-KIYO

ほかにも、1台を左右に分離してつかえる「パーソナルシネマスピーカー SDU-11」（税込 7990円 / 2026年11月発売）や、置いた場所を振動させてスピーカーに変える「振動スピーカー SVB-11 / SVB-21」（小：税込 2990円、大：税込 3990円 / 2026年11月発売）など、遊び心あふれるアイテムも揃っていました。

左：HST-11、中：HST-21、右：HST-31

Photo: SUMA-KIYO

続いて驚かされたのが、ワイヤレスヘッドホン3モデルです。実際に試聴してみたのですが、ノイズキャンセリングの効きと音質のクリアさに思わず唸ってしまいました。

### ワイヤレスヘッドホン HST-31（税込 9990円 / 2026年11月発売）

ANC（アクティブノイズキャンセリング）に加えて、没入感を高める空間オーディオに対応した最上位モデル。音に包み込まれるような立体的なサウンドが楽しめ、1万円を切る価格とは思えないリッチな聴き心地でした。

### ワイヤレスヘッドホン HST-21（税込 5990円 / 2026年11月発売）

5000円台ながらしっかりとANCを搭載し、周囲の騒音を抑えて音楽や作業に集中できるモデル。マルチポイント接続にも対応しているため、PCとスマホの切り替えもスムーズに行えます。

### ワイヤレスヘッドホン HST-11（税込 2990円 / 2026年11月発売）

約170gの軽量設計で、持ち運びや収納がしやすい折り畳み式モデル。1ボタンでシーンに合わせた音質切替えが可能で、初めてのワイヤレスヘッドホンにもぴったりです。

左から順に、EST-11、EOP-11、ESP-11、ESL11

Photo: SUMA-KIYO

同じく2026年11月発売のワイヤレスイヤホン4種類。用途別に4タイプが用意されているのですが、なんと全モデルが「税込 2990円」という驚きの価格で登場します。

### ワイヤレスイヤホン EST-11（税込 2990円 / 2026年11月発売）

耳にすっと収まる定番のインイヤー型。φ13mmの大きめドライバーを搭載し、低音から高音までバランスのよいサウンドと約6時間の連続再生、通話にも対応した万能モデルです。

### ワイヤレスイヤホン EOP-11（税込 2990円 / 2026年11月発売）

耳をふさがずに周りの音や声も聞こえるオープンイヤー型。家事や在宅ワークをしながらの「ながら聴き」に最適で、約4時間再生と通話に対応しています。

### ワイヤレスイヤホン ESP-11（税込 2990円 / 2026年11月発売）

IPX4の防滴仕様で運動中の汗や小雨に強いスポーツモデル。動いても落ちにくい形状で、約8時間の連続再生が可能です。

### ワイヤレスイヤホン ESL-11（税込 2990円 / 2026年11月発売）

個人的に一番面白いと感じたのがこちら。本体の出っ張りが小さく設計されており、横向きに寝転がっても耳が痛くなりにくいデザインのイヤホンです。

## アイデア満載の生活家電

Photo: SUMA-KIYO

オーディオ以外の生活家電も、日々の「ちょっとした不便」を解決してくれるアイデアの宝庫でした。

たとえば、この「壁掛けハンズフリードライヤー」（税込 9990円 / 2026年9月発売）。

その名の通り、壁に掛けたままハンズフリーで髪を乾かせるため、髪が長くて乾かすのに時間がかかる人や、ヘアドライ中にスマホをチェックしたい人、ドライヤーの重さで腕がだるくなりがちな人にとってはまさに救世主のようなアイテムです。

もちろん壁から外して手に持って使うこともでき、先端に絶妙なカーブ（角度）がついているので後ろ髪も無理なくブローできます。

Photo: SUMA-KIYO

そして、猫好きの僕の心を鷲掴みにしたのが「ペット（キャット）空気清浄機」（税込 1万9900円 / 2026年10月発売）。適用床面積約21畳、集塵フィルター・脱臭フィルター・埃センサーを備えた本格的な空気清浄機でありながら、なんと本体下部からランダムに「猫じゃらし」が飛び出してくる仕掛けを搭載しています。これには猫もまっしぐら間違いなし。

さらに本体上部には、爪を研いだり体を擦り付けたりしやすいカバーやブラシまで一体化されており、ペットとの暮らしを本気で考え抜いたユニークな一台になっていました。

## ドラム式導入のハードル激減

左から順に6kg、10kg、12kg

Photo: SUMA-KIYO

白モノ家電の主役として存在感を放っていたのが、暮らしに合わせて選べる3種類のドラム式洗濯乾燥機です。

一人暮らしに猛プッシュしたい「6kg ドラム式洗濯乾燥機」（税込 7万9900円 / 発売中）は、奥行53cmと縦型並みの超コンパクト設計。約1kgの衣類を60分で洗濯から乾燥まで仕上げる「特急洗乾コース」や、乾燥後の面倒な糸くず掃除が不要な点など、忙しい社会人のニーズを完璧に押さえています。

二人暮らしやファミリー向けには、奥行60cmの省スペースながら左右開きが選べ、洗剤自動投入も備えた「10kg ドラム式洗濯乾燥機」（税込 9万9900円 / 発売中）を展開。

さらに最上位の「12kg ヒートポンプ式 ドラム式洗濯乾燥機」（税込 14万9900円 / DGY色は2026年12月発売、WH色は発売済）は、大手顔負けのフラッグシップ機です。「7kg大容量ハイブリッド乾燥」による省エネ・速乾性能に加え、水で除菌する「OxyWave」まで搭載。これほどの高機能モデルが15万円以下で手に入るとなれば、ドラム式への買い替えハードルが一気に下がりそうです。

## お値段以上の裏側に潜入！

体験会のあと、なんと特別にニトリ大阪本部の「開発室」を見せていただけることに。

Photo: SUMA-KIYO

一歩足を踏み入れると、そこには製品の限界を試す専門の試験機がずらりと並んでいました。

コンセントの根元を何万回も曲げ伸ばしして断線をチェックする装置や、強い光で素材の経年劣化を調べる耐候性試験機、真夏から極寒まで過酷な温湿度環境を再現する巨大な「ウォークインチャンバー」など、まさに品質管理の要塞です。

Photo: SUMA-KIYO

極めつけは、建設品に約数千万円を投じたという騒音試験用の無響室。分厚い防音扉の先にある吸音材に囲まれた部屋で、洗濯機などの稼働音を精密にチェックし、日常で気にならないレベルまで静音性を追求しているそうです。

低価格を実現するために品質を削るのではなく、何一つおろそかにしない徹底した検証と技術者のこだわりがあるからこそ、本当に「お、ねだん以上。」の家電が生まれるんですよね。

2026年秋冬のニトリ家電、今後の展開から目が離せません。
