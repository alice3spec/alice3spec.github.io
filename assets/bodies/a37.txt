レノボ「Legion Go Beam」がリーク。低価格ポータブルゲーミングPCが近々発売？

Nov 27,2026 20:30

Kyle Barr - GIZMODO US［原文］（高橋真紀 / GIZMODOライター ）

画像に写っているのはレノボ「Legion Go S」。Image: Adriano Contreras / Gizmodo

何もかもの価格が高騰している昨今、特にガジェット類の値上がりはえげつなく、多くの人にとって手の届かない存在になりつつあります。

ポータブルゲーミングPCもしかり。Ayaneoのフラッグシップモデル「Ayaneo Next 2」は、5300ドル（約86万円）という超高額で販売されるほどです。

## トラックパッド廃止、液晶サイズを変更

そうしたなか、レノボから低価格のポータブルゲーミングPCが、今後数ヶ月以内に登場する可能性が浮上しています。

開発が噂されている新モデルは「Legion Go Beam」。すでにWindows Latestが製品画像をリークしています。

Image: Windows Latest

初代「Legion Go」や「Legion Go 2」と比較すると、コストを抑えるための設計がいくつか確認できます。

円形のDパッド、ABXYボタン、2つのアナログスティックはありますが、右下のトラックパッドがなくなりました。これは個人的には廃止されてもまったく問題なし。

Image: Windows Latest

4つのトリガーボタンも形状が変わっています。トリガーの入力方法をアナログとマイクロスイッチで切り替えるためのスイッチは省かれたようです。残念だけど、これも致命的な欠点ではない。

Image: Windows Latest

気になるのはディスプレイ。縦横比は16:10から16:9へ変更されており、これにより画面上下のベゼルがやや分厚くなっています。レノボの他モデルでおなじみの8インチや8.8インチよりも、画面が小さくなったように見えます。

Image: Windows Latest

## ストリーミング専用機になる？

Image: Windows Latest

また、製品名にある「Beam（ビーム）」という言葉から連想されるように、Legion Go Beamは近くのコンソールやクラウドからゲームをストリーミングして遊ぶタイプの製品になりそう。これはロジクール（Logitech）の「G Cloud」と同じ方向性です。

どのようなスペックが搭載されるのかは明らかになっていないものの、あまり大きな期待はしないほうがよさそうです。ストリーミング専用機であれば、最高クラスのハードウェアを搭載する必要はありません。

他メーカーのストリーミング専用機のスペックを見てみると、エイサーの「Nitro Blaze Link」はRAMがわずか1GB、ストレージが8GBと非常に控えめ。OSにはLinuxのディストリビューション（派生版）であるDebianを採用していますが、容量はこれを動かすだけでも精いっぱいといった具合です。

実際にNitro Blaze Linkを試した際は、コントローラーの操作性が安っぽく、あまり魅力を感じませんでした。

Legion Go Beamも本体だけで最新のAAAタイトル（大作ゲーム）を動かせるようなスペックはなくていいですが、負荷の軽い2Dゲームくらいは本体でプレイできるとうれしいですね。

リーク画像からは、本体にmicroSDカードスロットらしきものが確認でき、ストレージを拡張できそうです。この点から、ゲームを本体で直接動かす機能もある程度備えているのではないかと期待しています。

そうでなければ、ゲームをストリーミング再生するために、Wi-Fi接続に全面的に頼ることになります。あるいは、PlayStation 5のゲームをPS Remote Playでプレイするように、家庭内ネットワークを使ったローカルストリーミングにも対応してほしいところです。

## どこまで価格を抑えられるか

そして、何より気になるのがお値段です。

Valveの「Steam Deck OLED」は値上げされたものの、512GB版が13万7,980円、1TB版が16万7,980円です。ただし、現在は売り切れ中で購入できません。

今年発売されたストリーミング専用のポータブルゲーミングPCを見ると、「Asus ROG Xbox Ally X20」は1300ドル（日本では25万円前後）、「Acer Predator Atlas 8」は1450ドル（約20〜30万円）といった価格帯です。これまでの革新的なレノボの姿勢から、これらより安くなることを期待します。

しかし、メモリ価格の高騰は容赦ありません。

一般的なPCゲーマー向けにより手頃な選択肢として用意されたはずのLegion Go Sですが、高騰の影響を受け、Ryzen Z2 Goチップと512GBのストレージを搭載したモデルでさえ、価格は20万円近くまで跳ね上がっています。

2027年以降もお気に入りのゲーミングデバイスの価格は上がっていくのでしょうか。我々ユーザーにできるのは、事態が好転することを願いつつ、最悪の状況も覚悟しておくことくらいですかね。
